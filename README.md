Project overview. This project is an SEO content strategy created for Rajora Boutique Hotel in Jaipur as a  simulation project. The goal was to develop a content strategy by researching keywords, organizing them into content clusters, and turning those clusters into actionable content plans. Project structure. It includes two main sections: Content Pillar, with pillars like local Jaipur experiences and boutique stay experience. Clusters cover food, culture, shopping, heritage attractions, hotel rooms, amenities, and guest experience. Content plan: Translates those clusters into topics, primary and secondary keywords, content angles, structures, and CTAs. Tools and learning: SEMrush Keyword Research and Content Marketing Essentials, plus Google Sheets. Note. This is a portfolio or simulation project created to demonstrate practical SEO and content marketing skills.
